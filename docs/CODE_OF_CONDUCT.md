# Code of Conduct

Harmonia aims to be a respectful, collaborative, and inclusive protocol community.

## Our Standards

- Be respectful and constructive.
- No harassment, discrimination, or hate speech.
- No personal attacks.
- Assume good intent; critique ideas, not people.

## Scope

This Code of Conduct applies to:

- GitHub issues and PRs
- Community chats (Discord, Telegram, etc.)
- Documentation and comments

## Reporting

If you experience or witness unacceptable behavior:

- Open a private issue or contact the maintainers (to be listed).
- Provide context and links where possible.

Maintainers may take action including warnings, PR rejections, or bans from the project spaces.
