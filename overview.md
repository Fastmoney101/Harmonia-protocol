# Protocol Overview

Harmonia merges two paradigms into a single unified network:

1. **Hashgraph consensus** — inspired by Hedera's gossip-about-gossip and virtual voting
2. **Subgraph-based indexing** — inspired by The Graph's decentralized indexing protocol

## What Harmonia Provides

- High-throughput finality
- Multi-chain indexing
- Market-driven query fees
- AI-oriented data delivery

## Network Roles

| Role | Description |
|---|---|
| Consensus Nodes | Run hashgraph consensus and maintain ledger state |
| Indexers | Build and maintain subgraphs; serve queries |
| Curators | Stake tokens to signal high-quality data sources |
| Delegators | Delegate stake to indexers for passive rewards |
| AI Agents | Consume structured, verifiable data streams |

## Native Token

HMO (Harmonia Token) is the native utility, governance, and work token. It is used for:

- Staking (nodes, indexers, curators)
- Query fee payments
- Governance voting
- Epoch reward distribution
