# Tokenomics

HMO is the native token of Harmonia.

## Token Properties

| Property | Value |
|---|---|
| Name | Harmonia Token |
| Symbol | HMO |
| Decimals | 18 |
| Max Supply | 1,000,000,000 HMO |
| Type | Utility + Governance + Work Token |

## Utility

- **Staking**: Nodes and indexers stake HMO for security
- **Query fees**: Pay-per-query in HMO
- **Curator signaling**: Stake HMO to signal valuable subgraphs
- **Governance**: Vote on protocol proposals

## Emission

Harmonia uses a capped supply with exponential decay emission.

- E0 = 200,000,000 HMO (remaining supply)
- k = 0.25 (decay constant)
- t = years since genesis
