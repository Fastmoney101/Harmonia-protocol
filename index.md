# Welcome to Harmonia

Harmonia is a hybrid protocol combining:

- **Hashgraph-style consensus** — high-throughput, leaderless, aBFT consensus with deterministic finality
- **Decentralized indexing** — subgraph-based indexing with a query marketplace for multi-chain and off-chain data
- **AI-ready data streams** — structured, verifiable, real-time data for autonomous agents

## Why Harmonia?

Modern decentralized systems face two major bottlenecks: consensus throughput/fairness and data indexing/query accessibility. Harmonia solves both in a single unified network.
