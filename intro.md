# Introduction

Harmonia is a hybrid decentralized protocol that combines hashgraph-style consensus with decentralized indexing and query markets.

## What is Harmonia?

Harmonia merges two paradigms:

1. **Hashgraph consensus** — gossip-about-gossip and virtual voting for high-throughput, deterministic finality
2. **Subgraph-based indexing** — decentralized data indexing with a pay-per-query marketplace

## Key Features

- High-speed, leaderless consensus (10,000+ TPS)
- Deterministic finality (no forks)
- Decentralized, multi-chain indexing
- Market-driven query fees
- AI-ready real-time data streams
- Enterprise-grade governance
- Unified token economy (HMO)

## Architecture

Harmonia has two layers:

- **Consensus Layer**: Hashgraph DAG with gossip-about-gossip and virtual voting
- **Data Layer**: Subgraph-based indexing with GraphQL query API
