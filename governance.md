# Governance

Harmonia governance combines token voting, curator signaling, and node reputation.

## Governance Model

### Hybrid Council

Inspired by Hedera's enterprise council model — a council of global organizations provides enterprise-grade governance.

### Community Governance

Inspired by The Graph's open-source, token-driven ecosystem — any HMO holder can participate.

## Voting Power

VotingPower = StakedHMO + CuratorSignal + NodeReputation

## Proposal Types

- Parameter changes (fees, stakes, epoch duration)
- Treasury allocations
- Protocol upgrades
- Subgraph certification

## Voting Parameters

| Parameter | Value |
|---|---|
| Voting Period | 7 days |
| Quorum | 10% |
| Pass Threshold | 50% + 1 |

## Treasury

The treasury receives 5% of epoch rewards, 5% of query fees, and 100% of slashed tokens. Funds are used for grants, audits, infrastructure, and ecosystem growth.
